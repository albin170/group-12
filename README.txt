Environmental Impact Assessment & Green Infrastructure — Group 12

Website presentation generated from the supplied PowerPoint.

Features:
- All 40 original slides preserved as rendered presentation images.
- 16:9 responsive presentation surface.
- Fullscreen presentation mode.
- Keyboard navigation: Left/Right, PageUp/PageDown, Home, End.
- Space = autoplay toggle; F = fullscreen.
- Forest canopy, drifting leaves, mist and firefly animations outside the original slides.
- No text or slide content has been added on top of the original slide artwork.

Run locally:
1. Keep index.html and the slides folder together.
2. Open index.html in Chrome/Edge/Firefox.
3. Use F or the fullscreen button for presentation mode.
